# 🧠 Intelligent Resume Classifier

An AI-powered Resume Screening System that uses Natural Language Processing (NLP) and Machine Learning to automatically classify resumes into relevant job roles. This project helps streamline the hiring process by reducing manual effort and improving candidate shortlisting efficiency.

---

## 🚀 Features

* 📄 Upload resumes (PDF/DOCX)
* 🧹 Text preprocessing (stopword removal, tokenization)
* 🧠 Resume classification using ML models
* 📊 TF-IDF vectorization for feature extraction
* ✅ Candidate shortlisting system
* 🌐 Interactive UI built with Streamlit

---

## 🛠️ Tech Stack

* Python
* NLP (NLTK)
* Scikit-learn
* Pandas & NumPy
* Streamlit

---


## 📊 How It Works

1. Upload a resume (PDF/DOCX)
2. Text is extracted and preprocessed
3. TF-IDF converts text into numerical features
4. Machine Learning model predicts job role
5. Candidate is shortlisted based on classification
